# Reserva Escolar

Projeto prático da GitHub e GitHub Pages, desenvolvido com HTML, CSS e JavaScript.

## Problema

A escola possui equipamentos que podem ser utilizados por diferentes alunos e professores. Sem uma interface simples, consultar a disponibilidade e registrar uma reserva pode gerar dúvidas e conflitos de horário.

## Público

Alunos e professores que precisam utilizar equipamentos da escola.

## Três tarefas principais

1. Consultar os equipamentos disponíveis.
2. Fazer uma reserva informando responsável, data e horário.
3. Consultar e cancelar uma reserva.

## Funcionalidades

- Pesquisa de equipamentos.
- Filtro por categoria.
- Indicação de equipamento disponível ou reservado.
- Formulário com validação.
- Confirmação da reserva.
- Cancelamento com confirmação.
- Estado vazio quando não existem reservas.
- Mensagens de erro para entradas inválidas.
